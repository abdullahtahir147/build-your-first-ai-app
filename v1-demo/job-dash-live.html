How this works under the hood:
This app calls the free HackerNews API (no key needed, no signup) to find the latest "Who's Hiring" post, then fetches all the comments (each one is a job listing). It filters them by your search term and displays the results. The whole thing is ~50 lines of JavaScript in a single HTML file.

What you could automate next: Run this fetch on a schedule (a "cron job") so new jobs appear in your tracker every morning without you lifting a finger.
